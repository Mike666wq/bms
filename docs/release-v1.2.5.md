本版包含初步对接完成的本地与云端实时监测模块：本地采集并完整记录 BMS 数据，通过 HTTPS 心跳取得观看租约，向云端实时页面上传新鲜快照。已由用户验证 Win11 的模拟数据及真实串口数据上传和网页实时展示。

同时包含本地 SQLite 分期分库、可调整采集/记录间隔、Excel/CSV 流式导出、界面优化，以及云端连接分阶段诊断、脱敏错误日志、.NET/TLS 兼容性配置和 DPAPI 令牌迁移提示。

下载 `BmsRealtimeDemo-Windows-1.2.5.zip` 后完整解压，运行 `BmsRealtimeDemo.exe`。需要 .NET Framework 4.8，必须保留同目录的 EXE.config、lib、x64/x86 依赖。运行包不包含实验数据和设备令牌；更新前正常退出旧程序并保留原有数据、设置。
